# Шифратор и дешифратор Цезаря (Caesar Cipher Suite)

Комплект консольных инструментов на Python для шифрования и дешифрования текста с помощью алгоритма Цезаря.

---

## 📂 Структура проекта / Project Structure

* **`main.py`** — Главная точка входа. Интерактивная консольная программа с выбором режимов (шифрование, дешифрование, брутфорс, русский/английский языки).
* **`caesar_functional.py`** — Альтернативная компактная реализация алгоритма на функциях с использованием `ord()` и `chr()`.

---

## 🚀 Режимы работы и возможности

### 1. Интерактивное приложение (`main.py`)
Скрипт представляет собой удобный консольный мастер с валидацией ввода, который предлагает пользователю следующие настройки:
* **Двунаправленность:** Поддерживает как шифрование (сдвиг вправо), так и дешифрование (сдвиг влево).
* **Два языка:** Работает с английским (26 букв) и русским (32 буквы, без 'ё' согласно условиям платформы Stepik) алфавитами.
* **Режим Брутфорса (`shift = 0`):** Автоматически перебирает и выводит все возможные сдвиги алфавита для взлома неизвестного шифротекста.
* **Динамический сдвиг по длине слова (`shift = 100`):** Автоматически шифрует каждое отдельное слово на количество букв, которое в нём содержится.

### 2. Функциональная реализация (`caesar_functional.py`)
Упрощенная альтернативная версия кода, написанная по принципам чистой архитектуры:
* **Разделение обязанностей (Single Responsibility):** Логика разбита на узкоспециализированные функции (`encrypt_char`, `encrypt_word`).
* **Оптимальные вычисления:** Вместо последовательного поиска индекса в строке используются встроенные функции Юникода `ord()` и `chr()`, что обеспечивает скорость поиска $O(1)$.
* **Экономия памяти:** Для склеивания строк используются генераторные выражения внутри методов `.join()`, что минимизирует выделение лишней оперативной памяти под промежуточные списки.

---

## 📋 Общие правила обработки текста

* **Знаки препинания и цифры:** Любые неалфавитные символы (пробелы, точки, запятые, цифры) полностью игнорируются шифром и переносятся в итоговый текст без изменений.
* **Сохранение регистра:** Программа строго сохраняет оригинальный регистр (заглавные и строчные буквы) каждого символа.

## 🛠️ Используемые технологии и концепции

* Python 3.x
* Модульная арифметика (циклические сдвиги внутри алфавита)
* Работа с кодировкой символов (`ord` / `chr`)
* Управление циклами и валидация пользовательского ввода (`while True`)
* Генераторные выражения (Generator Expressions) и генераторы списков (List Comprehensions)
