# Шифратор / Дешифратор Цезаря 🔐

Простая консольная программа на Python, которая умеет шифровать и дешифровать текст с помощью классического алгоритма **Шифр Цезаря**. 

Проект разработан с учетом сохранения регистра символов и автоматического игнорирования знаков препинания, цифр и пробелов.

---

## 🚀 Функционал

- **Два режима работы:** Шифрование (сдвиг вправо) и дешифрование (сдвиг влево).
- **Мультиязычность:** Полная поддержка русского (32 буквы, без 'ё') и английского (26 букв) алфавитов.
- **Сохранение регистра:** Заглавные буквы остаются заглавными, строчные — строчными.
- **Валидация ввода:** Программа защищена от некорректных действий пользователя (проверяет числа, корректность выбора языка и режима).
- **Игнорирование спецсимволов:** Пробелы, знаки препинания, эмодзи и цифры остаются на своих местах без изменений.

---

## 🛠 Технологический стек

В проекте используются базовые, но важные концепции Python:
* Модульная арифметика (`%`) для циклического сдвига алфавита.
* Управляющие конструкции (`if/elif/else`, циклы `while`, `for`).
* Методы обработки строк (`.lower()`, `.isdecimal()`, `.index()`, `''.join()`).
* Работа со списками как с динамическими массивами.

## 💻 Как запустить

1. Убедитесь, что у вас установлен Python версии 3.x.
2. Скачайте файл с кодом (например, `caesar_cipher.py`).
3. Откройте терминал/командную строку в папке с файлом и запустите:

```bash
python caesar_cipher.py
```

## 📖 Пример работы

**Входные данные:**
* **Направление:** `ш` (шифрование)
* **Язык:** `р` (русский)
* **Шаг сдвига:** `1`
* **Текст:** `Умом Россию не понять!`

**Вывод программы:**
```text
Измененный текст:
Фнпн Спттйя ож рпоауэ!
```
