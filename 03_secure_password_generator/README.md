# 🔒 Secure Password Generator (Генератор безопасных паролей)

Интерактивный консольный скрипт на Python для генерации надежных паролей с гибкой настройкой параметров безопасности. Проект выполнен в рамках обучения на платформе Stepik.

## 🚀 Функционал
* Валидация пользовательского ввода (защита от некорректных данных через `.isdecimal()`).
* Выбор количества и длины генерируемых паролей.
* Настройка состава пароля: цифры, прописные и строчные буквы, спецсимволы.
* Опция автоматического исключения неоднозначных символов (`il1Lo0OI`).

## 🛠️ Стек технологий
* Python 3.x
* Модуль `random` (генерация случайных элементов)

## 💻 Инструкция по запуску
1. Откройте терминал в папке проекта.
2. Запустите скрипт командой:
   ```bash
   python main.py
   ```
3. Ответьте на интерактивные вопросы в консоли.
