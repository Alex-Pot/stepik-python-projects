# 🎮 Числовая угадайка (Number Guessing Game)

Консольная игра на Python, в которой пользователь сам настраивает верхнюю границу диапазона, а компьютер загадывает случайное число.

## 🚀 Особенности проекта:
* **Динамический диапазон:** Игра адаптируется под любое число `n`, введенное пользователем.
* **Архитектурный подход:** Логика игры вынесена в изолированную функцию с аргументами, что исключает утечки памяти и рекурсию.
* **Надежная валидация (Защита от дурака):** Кастомные проверки защищают программу от падения при вводе букв, пустых строк или чисел вне диапазона.
* **Красивый консольный UI:** Использовано правильное форматирование строк и управляющие символы (`\n`) для аккуратного отображения текста.

## 🛠️ Технологии:
* Python 3
* Модуль `random` (функция `randint`)
