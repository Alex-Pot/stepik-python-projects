# 🔮 Магический шар судьбы (Magic 8 Ball)

Интерактивное консольное приложение на Python, симулирующее знаменитый игрушечный шар предсказаний с 20 классическими вариантами ответов.

## 🚀 Особенности проекта:
* **Многоуровневая валидация (Защита от дурака):** 
  * Защита от пустых строк и случайных пробелов с помощью метода `.strip()`.
  * Элегантная проверка на наличие букв через сравнение регистров `question.lower() == question.upper()`. Игра не примет ввод из одних цифр или знаков препинания (вроде `12345` или `????`).
  * Контроль осмысленности: вопрос должен быть длиннее 5 символов.
* **Кастомная ИИ-анимация:** Реализован динамический эффект ожидания в цикле со сменой знаков `+` и `-` и увеличением числа точек с использованием возврата каретки `\r` и очистки буфера `sys.stdout.flush()`.
* **Автоматическое затирание:** Последний кадр анимации стирает служебные символы с экрана, оставляя в истории консоли только троеточие.

## 🛠️ Технологии:
* Python 3
* Модуль `random` (функция `choice` для случайного выбора ответа из списка)
* Модули `time` и `sys` (для управления задержками и выводом в терминал)
