# Игра «Угадайка слов» или «Виселица» (Hangman Game)

Классическая консольная игра-головоломка «Виселица», написанная на языке Python. Компьютер загадывает случайное слово из встроенного списка, а игрок должен угадать его по буквам или назвав слово целиком до того, как закончится количество попыток.

## 🚀 Особенности проекта

*   **Валидация ввода:** Игра принимает только буквы русского алфавита (включая букву «Ё»). Любые цифры, пробелы или спецсимволы отсекаются без потери попытки.
*   **Защита от повторов:** Система запоминает все ранее введенные варианты (как правильные буквы, так и ошибочные слова) и предупреждает игрока, если он пытается ввести их снова.
*   **Расход попыток:** Жизни игрока и состояние виселицы обновляются исключительно при совершении ошибки.

## 🛠 Стек технологий

*   **Язык:** Python 3.x
*   **Модули:** `random` (встроенный)

## 📋 Требования к установке

Для запуска игры вам понадобится установленный интерпретатор Python версии 3.6 или выше.

## 📦 Запуск игры

1. Склонируйте репозиторий или скачайте файл с кодом.
2. Откройте терминал/консоль в папке с проектом.
3. Запустите игру командой:
   ```bash
   python main.py
   ```
   *(Если вы переименовали файл с кодом, укажите ваше название вместо `main.py`)*

## 🎮 Правила и игровой процесс

1. На старте генерируется скрытое слово, отображаемое в виде нижних подчеркиваний `_ _ _ _`.
2. У вас есть **6 попыток** (ошибок). Каждая ошибка дорисовывает элемент виселицы.
3. Вы можете вводить:
   * **Одну букву:** если она есть в слове, откроются все её вхождения. Если нет — теряется 1 жизнь.
   * **Слово целиком:** если слово угадано верно — мгновенная победа. Если нет — теряется 1 жизнь.
4. После окончания раунда игра предложит начать заново.
